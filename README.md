# InternPath: Responsive Internship Board

A responsive student internship board built with **HTML, CSS and JavaScript**. Search and filter internships, view details, and apply through a validated form.

**Live demo:** https://yogitha-ram.github.io/internship-board/

## Features

- Search by role, company or skill
- Filter by domain (Full Stack, Data Analytics, AI and ML, UI/UX, Cyber Security) and work mode (Remote, Hybrid, On-site)
- Sort by newest, highest stipend or title
- Internship cards with a details pop-up and an application form
- Form validation for name and email, with duplicate applications blocked
- Loading, empty and error states, with a Retry button
- Responsive layout: 1 column on mobile, 2 on tablet, 3 on desktop
- Keyboard friendly, with visible focus, labelled fields and a skip link
- Mobile navigation menu and reduced-motion support

## Tech used

- HTML5 (semantic elements, dialog)
- CSS3 (Grid, Flexbox, custom properties, media queries)
- Vanilla JavaScript (no frameworks or libraries)

## Run locally

1. Download or clone this repository.
2. Open index.html in any browser. No install or build step is needed.

To preview the error state, open index.html?error

## Testing notes

- Checked at 360px, tablet and desktop widths, with no horizontal scrolling.
- Search, filters, sorting, pop-up and form validation tested in the browser.
- Sample data only. Companies and listings are fictional.
